Here is the Python code that calculates the first 10,000 terms of the series, multiplies the total by 4, and prints the result:

```python
def main():
    n_terms = 10000
    total = 0.0
    for i in range(n_terms):
        # The i-th term: 1/(2*i + 1) with alternating sign
        term = ((-1) ** i) / (2 * i + 1)
        total += term
    result = total * 4
    print('Approximation of pi using first 10000 terms of the series:')
    print(result)

if __name__ == '__main__':
    main()
```

